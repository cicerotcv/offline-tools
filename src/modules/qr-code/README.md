# QR Code Generator Tool

width: 100%
name: qr-code

## Overview

The QR Code Generator Tool provides a flexible way to create Quick Response (QR) codes for various data types like text or URLs. It offers extensive customization options for styling and technical parameters, all while processing data securely within the browser.

## Features

- **Instant Generation**: Create QR codes instantly from text, URLs, or other data.
- **Customization Options**:
  - **Error Correction**: Choose from Low (7%), Medium (15%), Quartile (25%), or High (30%) error correction levels to ensure scannability even if damaged.
  - **Size & Margin**: Adjust the pixel dimensions and white space margin around the code.
  - **Custom Colors**: Personalize the foreground (dark) and background (light) colors to match your branding.
- **Export**: Download the generated QR code as a high-quality PNG image.
- **Privacy First**: All generation happens locally using JavaScript. No data is sent to a server for processing.

## Usage

1.  **Enter Data**: Type or paste your content in the input text area.
2.  **Configure**: Adjust the technical settings and improved visual style using the configuration panel.
3.  **Preview**: See real-time updates as you type and tweak settings.
4.  **Download**: Click the download button to save your QR code.
